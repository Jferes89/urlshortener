# 🔗 Encurtador de URL - API REST com MongoDB

Este é um projeto simples de **encurtamento de URLs** desenvolvido com o objetivo de **estudar os padrões REST** e a **integração do MongoDB** em uma aplicação backend.

## 🎯 Objetivo do Projeto

O projeto tem como finalidade:

- Aplicar os conceitos de **API RESTful**, utilizando boas práticas de rotas, verbos HTTP e estrutura de responses.
- Implementar um serviço de **encurtamento de URLs** funcional.
- Estudar e praticar a integração com o **MongoDB**, utilizando-o como banco de dados para persistência de dados.
